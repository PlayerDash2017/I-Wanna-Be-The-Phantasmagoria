<-- I Wanna Be The Phantasmagoria -->

Un fangame de I Wanna Be The Guy inspirado en Touhou 9 y Touhou 19, este proyecto esta en desarrollo pero poco a poco voy agregando mas cosas.

-- Controles --

Teclado:

- Teclas de direccion: Moverte
- Shift: Salto/Doble Salto
- Z: Disparo
- Mantenter y soltar Z: Cargar poder magico y usarlo

Mando:

- Cruceta: Moverte
- A/X: Salto/Doble Salto
- X/Cuadrado: Disparo
- Mantener y soltar X/Cuadrado: Cargar poder magico y usarlo
